自分のGoogleアカウントでログインすると、その人の無料枠で解析します。

APIキーで使う 未設定

キーはこのPCのこのブラウザにだけ保存されます。送り先はGoogleのGemini APIだけです。

  1. Googleアカウントで aistudio.google.com/apikey を開き、キーを作成してコピーします（無料・カード登録不要）。
  2. 支払い情報（Billing）は登録しないでください。登録しなければ無料枠を超えても課金されず、その日は止まるだけです。

無料枠では、送った資料がGoogleのサービス改善に使われる規約です。公開前の機密資料は入れないでください。

代表者向け：Googleログインを使えるようにする（最初に1回だけ）

Googleの決まりで、ログイン機能を使うアプリは登録が必要です。代表者が1回だけ次の作業をすると、あとは全員が自分のアカウントでログインでき、それぞれ自分の無料枠を使います。

A. アプリをネット上に置く場所を作る（GitHub Pages・無料）

  1. github.com で無料アカウントを作ります。
  2. 右上の「＋」→「New repository」。名前は例えば soui-navi、「Public」を選んで作成します。
  3. 作成したリポジトリの「Settings」→「Pages」で、Branch を main にして保存します（ファイルは手順Cで入れます）。
  4. 公開URLは https://ユーザー名.github.io/soui-navi/ になります。次の手順では 「https://ユーザー名.github.io」 の部分だけを使います。

B. Googleにアプリを登録する（Google Cloud・無料）

  1. console.cloud.google.com を開き、上部のプロジェクト選択から「新しいプロジェクト」を作ります（名前例：創意工夫ナビ）。
  2. 検索欄で「Cloud Resource Manager API」を検索して「有効にする」を押します。同じように「Generative Language API」も有効にします。
  3. メニュー「Google Auth Platform」（または「APIとサービス」→「OAuth同意画面」）で「開始」→ アプリ名「創意工夫ナビ」、サポートメールに自分のアドレス、対象は「外部」を選んで作成します。
  4. 「対象」（テストユーザー）に、使う人全員のGmailアドレスを追加します（100人まで。あとから追加もできます）。
  5. 「データアクセス」→「スコープを追加」で、次の2つを手入力して保存します。
    https://www.googleapis.com/auth/cloud-platform
    https://www.googleapis.com/auth/generative-language.retriever
  6. 「クライアント」→「クライアントを作成」→ 種類「ウェブ アプリケーション」。「承認済みの JavaScript 生成元」に Aの https://ユーザー名.github.io を入れて作成します。
  7. 表示された「クライアントID」（…apps.googleusercontent.com で終わる文字列）をコピーします。

C. 設定入りのファイルを作って置く

保存される index.html を、Aのリポジトリの「Add file」→「Upload files」でアップロードします。数分後に公開URLで開けます。

D. 使う人に伝えること

  1. 公開URLを開き、「Googleでログイン」を押します。
  2. 「Googleはこのアプリを確認していません」と出たら「続行」を押します（社内用のため正常です）。
  3. 権限の確認画面では、すべてにチェックを入れて「続行」を押します。
  4. 初めての人は、先に一度 aistudio.google.com を開いて利用規約に同意してください（自分の無料枠が作られます）。
